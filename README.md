# WDIO Framework EPAM Task

This repository contains the practical task implementation focusing on refactoring the test automation framework to implement the **Page Object Model (POM)** design pattern, improving maintainability, reusability, and clean code principles.

## Local Installation & Execution

1. Clone the repository and enter the directory:

```bash
git clone <repository-url>
```

2. Install dependencies:

```bash
npm install
```

3. Set up the environment variables:

```bash
cp .env-template .env
```

4. Run the test suite:

```bash
npm run test
```
